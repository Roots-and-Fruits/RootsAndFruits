# SLK-TS100 주문서 인쇄

## 용지 규격

[SEWOO 공식 제품 안내](https://www.miniprinter.com/page/?pid=product_view&pr_id=8)에서 SLK-TS100은 3인치 감열식 프린터이며 용지 폭 80mm, 실제 인쇄 폭 72mm(576 dots/line), 해상도 203dpi로 안내합니다. 본문은 72mm 폭의 검정 글자와 구분선으로 구성합니다. 용지 길이를 고정하지 않고 선택한 드라이버의 용지 설정에 맡깁니다.

## 사용 방법

1. 출력할 PC에 모델과 운영체제에 맞는 제조사 드라이버를 설치하고, 운영체제의 프린터 테스트 페이지가 출력되는지 확인합니다. 드라이버 다운로드는 위 공식 제품 페이지에 있습니다.
2. 프린터 속성에서 80mm 영수증 용지를 선택합니다. 연속용지·용지 길이·자동 절단 관련 옵션은 드라이버에서 실제 지원하는 설정에 맞춥니다.
3. 카운터 또는 주문 관리 목록에서 주문을 열고 상세 화면의 **주문서**를 누릅니다. 목록에는 인쇄 버튼을 표시하지 않습니다. 관리자 전용 새 창에서 최신 주문을 조회합니다.
4. 내용 확인 후 **인쇄**를 눌러 브라우저 인쇄창을 엽니다. 대상 프린터를 SLK-TS100으로 선택하고 용지 80mm, 배율 100%, 여백 없음, 머리글/바닥글 해제로 설정합니다.
5. 처음에는 짧은 주문 1건으로 좌우 잘림과 여백을 확인한 뒤, 배송지가 여러 개인 긴 주문도 확인합니다. 고정 길이 용지 설정에서는 여러 장으로 나뉠 수 있습니다. 잘리면 드라이버 용지 폭과 브라우저 배율부터 확인합니다.

사이트는 프린터 설치, 기본 프린터 선택, 자동 절단, 인쇄창 없이 바로 출력하는 설정을 변경하지 않습니다. 브라우저 인쇄는 [`window.print()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/print)를 사용합니다. 태블릿에서의 실제 출력 가능 여부는 운영체제·프린터 연결 방식과 드라이버 지원에 따라 별도 확인해야 합니다.

## 출력 내용과 상태

- 주문번호, 한국 시간 기준 접수 시각, 일반/체험 구분, 결제 상태와 방식, 보내는 분을 표시합니다. 취소된 주문은 취소 표시와 기록된 이전 결제 방식을 유지합니다.
- 상품별 합산 수량·단가·금액과 주문의 저장된 할인·합계를 사용합니다. 현재 상품 정보로 과거 주문을 다시 계산하지 않습니다.
- 배송지는 저장된 순서대로 받는 분·연락처·주소·출발 날짜·상품 수량·운영 메모를 표시합니다. 메모가 비어 있으면 생략합니다.
- 체험상품은 이전 스냅샷에 남은 `택배 1kg ·` 같은 임시 접두어를 기존 공통 표시 규칙으로 제거합니다. 주문 DB 자체를 수정하지 않습니다.
- 출력/인쇄 취소/재인쇄 모두 결제나 배송 상태를 변경하지 않습니다. **주문서 인쇄와 택배 엑셀 출력은 별개**이며 주문서만 인쇄한 주문은 기존 규칙대로 엑셀 출력 전 취소할 수 있습니다.
- 출력 중 다른 관리자가 상태나 메모를 변경했다면 **다시 불러오기**로 최신 내용을 조회합니다. 접수 당시 상품·주소 기록을 직접 편집하는 기능은 아닙니다.

## 검증 범위

격리된 가상 주문으로 화면·인쇄용 CSS·관리자 접근 권한·인쇄 후 주문 상태 유지를 자동 검증합니다. 브라우저 테스트에서는 OS 인쇄창 호출을 대역으로 바꿔 실제 종이를 출력하지 않습니다. 실제 SLK-TS100 연결, 드라이버 설정, 용지 절단과 한글 실물 출력은 현장 프린터에서 확인해야 합니다. DB 마이그레이션은 필요 없습니다.
