- 6번의 출력 상태는 조건부 자료로 직접 구성했다. 엑셀 출력·실제 택배 인계가 수행됐다는 의미가 아니다. 송장은 0으로 시작하는 가상 번호이며 외부 택배 조회를 실행하지 않는다.

### 실제 접수와 DB 보완 대조

- Aside 비회원 일반 주문 2번: 배송지 2곳·89,000원. 체험 주문 3번: 배송지 1곳·7,000원.
- Aside 회원 일반 주문 4번: 배송지 2곳·43,000원(상품 45,000원·할인 2,000원). 회원 체험 주문 5번: 배송지 2곳·21,000원.
- 테스트 DB 읽기 대조에서 2·3번은 `guest`·회원 연결 없음, 4·5번은 `kakao`·회원 연결 있음을 확인했다. 4건 모두 항목 단가×수량/할인/배송지 합계/전체 합계가 일치한다. 요청 ID는 4개로, UI 접수 4건과 일치한다.
- 10월 12일 실제 접수 4건의 요청일 10월 14일·처리일 10월 13일을 확인했다. 회원 주문 내역 화면에서도 출발 예정일 10월 13일이 표시되지만 접수 전 일반 배송 단계는 구체적 요청일을 보여주지 않는다.
- 대조 시점 알림 설정은 계속 꺼짐이며 알림 내역은 0건이다. 내부 DB 대조 결과는 `db-audit.json`에 저장하고 UI 관찰과 구분한다.
- 조건부 자료 준비 후 DB 대조: QA 주문 26건 = 실제 UI 접수 4건 + 준비용 22건. 요청 ID도 26개이며 모든 주문 금액과 배송지·상품 합계, 요청일/처리일의 하루 차이가 일치한다. 알림 OFF·내역 0건을 다시 확인했다.
- 최종 DB 대조 시각은 2026-10-12 02:24:51 KST다. 알림 `enabled=false`·`test_mode=true`·알림 내역 0건, QA 주문 26건·고유 요청 ID 26개와 금액 일치를 재확인했다. 운영 DB는 접근·수정하지 않았다.
- 자동 승인 검토가 내부 DB 주문 메타데이터를 Aside 세션으로 전달하는 작업을 거부했다. 해당 데이터를 Aside로 전송하지 않고 주 에이전트가 로컬 보고서에 별도로 반영한다. 일반 브라우저 QA는 계속 수행한다.

## 확인 필요 또는 실행 제약

- **일반 배송 날짜 표시와 시트 기대의 차이:** QA-035/036은 화면에 요청 날짜가 표시되는 것으로 작성됐지만, 실제 UI는 ‘가능한 빠르게’ 안내만 보여준다. `docs/requirements.md` §9는 D+2 요청·하루 차감 저장을 확정하며 일반 날짜의 화면 표시를 요구하지 않는다. 따라서 이를 앱 결함으로 보고 날짜 UI를 추가하지 않았다. 실제 접수 DB의 날짜 계산은 별도 확인했으며, 화면 날짜 비교 항목은 보류로 남긴다.
- **배송 안내 표현의 의미:** 현재 `src/features/orders/components/delivery-date-step.tsx:97`의 ‘배송 출발까지 2일’ 안내는 기존 `RootsAndFruitsDeliveryServiceClient/src/components/common/steps/SelectDeliveryDate/SelectDeliveryDate.tsx:95`에도 있다. 기존 클라이언트는 D+2를 보내고 `RootsAndFruitsDeliveryServer/src/main/java/com/rootandfruit/server/api/domain/DeliveryInfo.java:91`은 하루를 차감한다. 기존 유지 요구에 맞춰 변경하지 않았다. 향후 고객에게 구체적인 발송일/수령일을 약속하려면 요청 날짜·처리 날짜의 운영상 의미를 먼저 확정해야 한다.
- 보류 12개는 다음과 같다. QA-035/036은 위 일반 날짜 표시 기대사항, QA-094는 실제 Aside 회원 모바일 크기 변경 미지원, QA-098은 Aside의 회원 Space 키 전달 확인 불가, QA-104는 기존 카카오 세션의 즉시 성공으로 취소 화면을 재현하지 못한 항목이다. COND-08은 두 번째 카카오 계정 부재, COND-09~14는 실제 Aside의 네트워크 실패·저장소 차단 제어 미지원이다. 격리 자동 테스트로 확인한 범위를 별도 기록했으며 실제 연동 통과로 대체하지 않았다.
- 물리 휴대폰·프린터·실제 알림톡·운영 배포 환경은 이번 localhost 고객 QA 범위가 아니다.
