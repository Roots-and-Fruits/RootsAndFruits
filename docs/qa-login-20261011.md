# 커밋 전 QA — 로그인 상태 변경과 주문 진입

작성일: 2026-10-11. 대상: 현재 미커밋 작업, `http://localhost:3000`.

## 범위와 실행 조건

- 사용자 최종 요청: 로그인·로그아웃 및 로그인 상태 변경에 따른 흐름만 확인한다. 실제 회원 탈퇴는 실행하지 않는다. 최초 카카오 로그인은 사용자가 준비했고, 이후 테스트 앱의 카카오 로그인 버튼을 통한 재로그인은 사용자가 허용했다.
- 로컬은 `roots-and-fruits-test`에 연결되어 있다. 운영 사이트·운영 DB·Vercel 설정은 대상이 아니다.
- 시작 전 확인: 로컬 `ALIGO_ENABLED=false`, `ALIGO_TEST_MODE=true`; 테스트 DB `enabled=false`, `test_mode=true`.
- 입력용 가상 이름은 `QA1011` 접두어, 전화번호는 `01000000000`을 사용한다. 기존 테스트 데이터를 수정하거나 실제 주문을 접수할 필요는 없다.
- Aside는 지정된 localhost QA 탭을 조작한다. 사용자는 다른 사이트 탭을 사용해도 되지만 같은 localhost의 로그인 상태 변경·QA 탭 조작은 동시에 진행하지 않는다. 창을 나눠도 인증은 공유된다.
- 결과는 통과 / 실패 / 보류로 기록한다. 아직 실행하지 않은 항목은 대기다. 커밋·푸시·배포는 이번 QA에 포함하지 않는다.

## 격리된 자동 테스트

## 실행 기록

- 시작 전 localhost:3000 실행, 테스트 프로젝트 연결, 알림 차단을 확인했다.
- 자동 UI 테스트 45건 모두 통과(4.6분), 개인정보 초기화 단위 테스트 1건 통과. 휴대폰 로그인 안내 모달과 태블릿 주문 진입 캡처를 시각 확인했다.
- 실행 명령: `./node_modules/.bin/playwright test --config playwright.admin.config.ts auth.spec.ts order-login.spec.ts account-navigation.spec.ts customer-account.spec.ts --grep '(login|logout|session|OAuth|late order response|guest prompt)' --grep-invert '(deletion|customer API|address save)'`
- 단위 테스트: `node --import tsx --test tests/unit/customer-cleanup.test.ts`.
- 자동 테스트는 격리된 fixture 환경에서 실행했으며 실제 localhost의 수동 QA 결과는 위 표에 별도로 기록한다.

## Aside 최종 결과

- 세션 `mzCM5lxMTwSienHg`에서 실제 테스트 카카오 로그인 → 일반/체험 임시 입력 → 새로고침 → 로그아웃 → 다중 탭/뒤로 가기 → 비회원 안내/이어쓰기 → 카카오 재로그인을 수행했다.
- L01~L10은 통과했다. 로그인/로그아웃 때 두 종류 입력이 지워졌고, 기존 주문 탭의 헤더도 변경됐다. 로그아웃한 마이페이지는 회원 내역 대신 ‘로그인 후 이용해주세요’를 표시했다. 비회원 주문을 막는 만료/로그인 확인 오류는 재현되지 않았다.
- L11은 공통 로딩 표시와 정상 화면 도착을 실제로 확인했다. 빠르게 전환되는 모든 중간 프레임을 수동으로 관찰하지는 못했으며, 세션 요청 지연 상황과 중복 요청/이전 로딩 문구 검증은 A02의 자동 테스트로 보완했다.
- 실제 카카오 재로그인은 버튼 클릭 후 추가 인증 없이 완료됐다. 일반/체험의 비회원 QA 이름이 모두 지워지고 기존 다른 탭에도 회원 메뉴가 반영됐다.
- 실제 회원 탈퇴·주문 접수·주소록/기본값 변경·알림 발송은 하지 않았다. 관리자 구분·접근 차단은 격리된 자동 테스트에서 검증했다. 운영 환경은 이번 QA 대상이 아니다.
- 발견한 기능 오류는 없다. Aside의 전화번호 입력 후 형식 불일치는 자동 하이픈 표시를 기대값과 비교한 도구 오류였으며, 새 화면에서 정상 입력을 확인했다. 뒤로 가기 도구의 탐색 대기 시간 초과도 실제 도착 화면을 확인해 구분했다.
- 전체 페이지 캡처 하단의 반복처럼 보이는 영역은 뷰포트 캡처와 DOM에서 재현되지 않았다. 실제 중복 헤더 문제로 판정하지 않았다.
- 최종 메인 QA 탭은 `http://localhost:3000/`의 개인 회원 로그인 상태다. 소스 코드 수정·커밋·푸시는 하지 않았다.
- 증거 파일은 Git 제외 `test-results/qa-login-20261011/`에 보관한다: 자동 테스트 로그, 휴대폰/태블릿 모달, Aside 비회원 상품·최종 회원 홈 캡처. 이 문서만 신규 QA 기록으로 추가한다.
